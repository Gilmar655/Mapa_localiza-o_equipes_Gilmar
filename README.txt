# Site – Acompanhamento de Equipes em Campo | Região Leste

Arquivo principal: `index.html`

Atualizações desta versão:
- Base de projetos atualizada a partir da planilha enviada.
- Link do Google My Maps incluído no painel do mapa.
- Inclusão do filtro por Data de Programação, integrado aos filtros de Parceira, Status e Tipo.

Como publicar no GitHub Pages:
1. Extraia o ZIP.
2. Envie os arquivos `index.html` e `README.txt` para o repositório do GitHub.
3. Ative o GitHub Pages no repositório, apontando para a branch principal.

Como publicar no Netlify:
1. Acesse https://www.netlify.com/
2. Entre na conta.
3. Arraste a pasta deste projeto para a área de deploy.
4. O Netlify criará um link público automaticamente.

Observação: este site usa mapa via OpenStreetMap/Leaflet e os dados do Excel foram incorporados no `index.html`.
